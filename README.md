# Дашборд тестирования креативов

Интерактивный дашборд для анализа результатов тестирования рекламных креативов (ролики и аниматики). Построен на основе данных из «Базы норм» — внутренней таблицы с результатами опросов.

## Быстрый старт

### Вариант 1: Просто открыть файл
Откройте `dashboard.html` в любом браузере. Файл полностью автономный — все библиотеки и данные встроены внутрь.

### Вариант 2: Локальный сервер (для доступа с других устройств)
```bash
python3 server.py
```
Сервер запустится на порту 8899. Ссылку для доступа с других устройств в той же сети он покажет в терминале.

## Структура дашборда

Дашборд состоит из 5 вкладок:

### 1. Обзор
- **Средние значения** по 5 ключевым метрикам (рассчитаны по всем 67 креативам)
- **Сравнение креативов** — выбор до 8 роликов, отдельная диаграмма по каждой метрике, таблица сравнения
- **Топ-5 и Анти-Топ-5** по каждой метрике с указанием среднего

### 2. Креативный рейтинг
Сортируемая таблица всех креативов с цветовой индикацией отклонения от среднего. Включает:
- Все ключевые метрики
- Δ Намерение (отклонение от среднего)
- Индекс креатива (среднее по 4 метрикам: Нравится, Понятность, Уникальность, Намерение)

### 3. Бренд-диагностика
- KPI: Brand Recall, Product Recall, Узнаваемость, Соответствие бренду, Индекс чистоты коммуникации
- Графики Brand Recall и Узнаваемости по продуктам
- Диаграмма правильных/неправильных ответов о функциях
- Детальная таблица

### 4. Драйверы намерения
- Корреляция Пирсона каждой метрики с «Намерением воспользоваться»
- 4 scatter-графика (Нравится, Понятность, Уникальность, Узнаваемость × Намерение)
- Горизонтальный рейтинг топ-30 креативов по намерению

### 5. Сравнение форматов
- Средние метрики по формату (10 сек, 15 сек, 20 сек, 25 сек, 30 сек, Ролик, Ролик + строка)
- Средние метрики по типу производства (Стандарт, ИИ, Продакшн)
- Детальная таблица с цветовой индикацией

## Фильтры

На вкладках 2–5 доступны фильтры:
- **Продукт** (Поиск с Нейро, Я.Бро, GigaChat и др.)
- **Кампания**
- **Период** (фев.25, май.25, …)
- **Формат** (10 сек, 30 сек, Ролик, …)
- **Таск** (номер задачи MR-XXXX)

## Метрики

| Ключ в данных | Название | Описание |
|---|---|---|
| `intent` | Намерение | Захотелось приобрести / воспользоваться (топ-1 по шкале) |
| `like` | Нравится | Насколько нравится ролик (топ-2) |
| `clarity` | Понятность | Понятность идеи ролика (топ-1) |
| `uniqueness` | Уникальность | Уникальность и непохожесть на другие (топ-2) |
| `brandRecognition` | Узнаваемость | Узнаваемость бренда в ролике (топ-2) |
| `brandRecall` | Brand Recall | Верно назвали бренд (открытый вопрос) |
| `productRecall` | Product Recall | Верно назвали продукт / фичу (открытый вопрос) |
| `brandFit` | Соответствие бренду | Насколько ролик соответствует образу бренда (топ-2) |
| `interesting` | Интересно | Интересно ли было смотреть (топ-2) |
| `relevance` | Актуальность | Актуальность предложения (топ-2) |
| `brandAttitude` | Отношение к бренду | Отношение к бренду улучшилось (топ-2) |
| `correctFeatures` | Функции ✓ | Доля правильно названных функций |
| `incorrectFeatures` | Функции ✗ | Доля неправильно названных функций |


## Обновление данных

Если появились новые данные в таблице:

1. Скачайте обновлённую таблицу как CSV и положите в папку проекта (замените существующий CSV)
2. Запустите парсер:
   ```bash
   python3 build_dashboard.py
   ```
3. Соберите автономный файл:
   ```bash
   python3 bundle.py
   ```
4. Откройте `dashboard.html`

**Важно:** если структура таблицы изменилась (добавились/удалились строки), нужно обновить номера строк в `build_dashboard.py` (массив `metric_rows` и индексы строк `base_row`, `link_row`).

## Особенности

- **Тёмная и светлая тема** — переключатель в правом верхнем углу, выбор сохраняется в localStorage
- **Ссылки на видео** — названия креативов кликабельны, ведут на RuTube (если ссылка есть в таблице)
- **Средние считаются по всем 67 креативам** из таблицы, а не из предрассчитанного столбца CSV
- **Цветовая индикация** — зелёный = выше среднего на 2+ п.п., красный = ниже на 2+ п.п.
- **Индекс креатива** = среднее значение по 4 метрикам (Нравится, Понятность, Уникальность, Намерение)
- **Индекс чистоты коммуникации** = правильные ответы о функциях − неправильные ответы

## Технологии

- **Chart.js 4.5.1** — графики (bar, scatter, line)
- **chartjs-plugin-datalabels 2.2.0** — подписи значений на графиках
- **Python 3** — парсинг данных и сборка
- Без фреймворков, без сборщиков, без npm — чистый HTML/CSS/JS
